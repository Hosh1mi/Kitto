# Kitto

术术人歌单补全计划～这个歌单收集了大多数群友在ktv唱过的歌并做了简单评级～

## 评分标准

以下除了`range`以外均为主观演唱感受评分

### 1.`range`（音域与音区）

考察歌曲是否音域跨度大，或存在需要长时间维持的困难音区

### 2.`melody`（旋律与音准）

考察旋律是否规律，难以预测

### 3.`rhythm`（节奏与速度）

考察是否存在复杂或密集的节奏组合

### 4.`breath`（气息与耐力）

考察歌词长度与换气机会

### 5.`pronunciation`（咬字与发音）

考察发音难度与歌词密集程度

### 6.`technique`（演唱技巧）

考察歌曲是否需要混声、真假转换、气息支撑、强弱变化、音色控制，情感表达等技巧

### 7.`stability`（演唱稳定与完整性）

考察歌曲的容错率，以及若出现局部失误，是否会影响后续演唱
