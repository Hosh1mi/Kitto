# Kitto

## Quick Start

维护/添加新歌曲在`data/songs`下添加新json文件即可，评级系统可通过`config.json`进行更改。

脚本使用：
```bash
python scripts/generate.py
```
## 评分维度

### 1. `range`（音域与音区压力）

考察歌曲的最高音、最低音、整体音域跨度，以及是否需要长时间停留在高音区、低音区或换声区。

- **1 分**：音域集中，旋律大多位于舒适音区，几乎没有明显的高低音挑战。（例：**《ハロ／ハワユ》- ナノウ**，整体音区相对平稳）
- **3 分**：音域跨度较明显，存在需要专门练习的高音或低音段落，但困难音区并不贯穿全曲。（例：**《ODDS & ENDS》- ryo**，副歌具有明显的高音要求）
- **5 分**：音域跨度极大，或长时间维持困难音区，频繁跨越换声区，对发声能力提出极高要求。（例：**《ローリンガール》- wowaka**，副歌持续的高音区演唱）

### 2. `melody`（旋律与音准难度）

考察旋律的音程变化、规律性，以及是否存在大跳、半音变化或难以预测的旋律走向。

- **1 分**：旋律走向自然，主要由重复音和简单级进构成，音准容易掌握。（例：**《千本桜》- 黒うさP**，主歌旋律具有较强的规律性）
- **3 分**：存在一定程度的音程跳跃或半音变化，需要通过练习才能稳定唱准。（例：**《深海少女》- ゆうゆ**，部分旋律需要注意音高衔接）
- **5 分**：频繁出现跨度较大的音程跳跃、不规则旋律或难以预测的音高变化，即使熟悉歌曲也容易跑调。（例：**《アンノウン・マザーグース》- wowaka**，旋律变化密集且音高转换频繁）

### 3. `rhythm`（节奏与速度难度）

考察歌曲的 BPM、音符密度、切分音、节奏变化，以及是否存在高速演唱或 RAP 段落。

- **1 分**：节拍规整，速度适中或偏慢，歌词与旋律的节奏容易跟随。（例：**《Just Be Friends》- Dixie Flatline**，主体节奏相对规律）
- **3 分**：具有正常的流行乐律动，包含一定的切分音、快速音符或节奏变化。（例：**《ワールドイズマイン》- ryo**，部分段落需要注意节奏与歌词的配合）
- **5 分**：包含极高速音符、密集切分或复杂的节奏组合，极容易出现抢拍、拖拍或节奏错位。（例：**《初音ミクの消失》- cosMo@暴走P**，高速连续演唱段落）

### 4. `breath`（气息消耗与演唱耐力）

考察乐句长度、换气机会、连续高音和密集歌词对气息的消耗，以及完整演唱所需的体力。

- **1 分**：乐句较短，换气位置充足，几乎不需要特殊的气息规划。（例：**《ハロ／ハワユ》- ナノウ**，多数乐句具有较自然的换气机会）
- **3 分**：存在较长乐句或连续演唱段落，需要一定的气息支撑和换气安排。（例：**《カゲロウデイズ》- じん**，部分连续乐句需要合理分配气息）
- **5 分**：换气机会极少，长乐句、高密度歌词或持续高音造成极大的气息与耐力压力。（例：**《ノンブレス・オブリージュ》- ピノキオピー**，大量连续歌词与紧张的换气安排）

### 5. `pronunciation`（咬字与发音难度）

考察歌词密度、发音速度，以及连续辅音转换、促音、拗音、长音等对咬字清晰度的影响。

- **1 分**：歌词密度较低，发音时间充足，咬字自然清晰，几乎没有绕口的词组。（例：**《ハロ／ハワユ》- ナノウ**，多数段落的歌词发音相对舒缓）
- **3 分**：具有一定的歌词密度，包含连续发音、较快的词组或需要专门练习的咬字组合。（例：**《ドーナツホール》- ハチ**，部分段落需要注意连续咬字的清晰度）
- **5 分**：歌词极其密集，包含大量高速音节、复杂发音转换或绕口令式组合，对舌部灵活性要求极高。（例：**《裏表ラバーズ》- wowaka**，高密度歌词与连续快速咬字）

### 6. `technique`（演唱技巧与声音控制）

考察演唱过程中所需的混声、真假声转换、气息支撑、声音强弱变化、音色控制及爆发力等技巧。

- **1 分**：主要使用自然、平稳的发声方式即可完成，不需要明显的特殊技巧。（例：**《ハロ／ハワユ》- ナノウ**，可以通过较自然的声音完成基本旋律）
- **3 分**：部分段落需要明确的气息支撑、声区衔接或声音动态控制，具有一定的技巧要求。（例：**《メルト》- ryo**，副歌高音需要合理的发声协调）
- **5 分**：需要高水平的声区转换、混声控制、声音动态变化或持续的高强度发声，对技巧和控制力要求极高。（例：**《命に嫌われている。》- カンザキイオリ**，高强度翻唱版本中副歌的爆发力与声音控制）

### 7. `stability`（完整演唱稳定性）

考察从头到尾连续演唱时的容错率，包括难点之间的衔接、疲劳累积、失误恢复能力，以及局部失误是否容易影响后续演唱。

- **1 分**：整体演唱负担较小，难点分布稀疏，即使偶尔失误也容易恢复。（例：**《ハロ／ハワユ》- ナノウ**，歌曲结构与演唱节奏相对平稳）
- **3 分**：存在若干需要集中注意力的段落，状态波动可能导致跑调、节奏错误或气息不稳。（例：**《カゲロウデイズ》- じん**，快速段落与较高音区的衔接需要一定稳定性）
- **5 分**：整曲容错率极低，难点密集且连续出现，容易因一次换气失误、节奏错位或体力下降引发连锁问题。（例：**《初音ミクの消失》- cosMo@暴走P**，连续高速演唱对整曲稳定性要求极高）

### 演唱建议

<details><summary>からくりピエロ</summary>
<p>虽然歌曲中存在B段到副歌、落副歌到最后副歌等转调变化，但整体音域并不宽广，因此非常推荐给刚开始接触VOCALOID歌曲的初学者。演唱副歌时，可以尝试每拍用手指画一个圆，配合歌曲的律动，这样会明显更容易唱出自然流畅的感觉。</p>
</details>

<details><summary>KING</summary>
<p>只要能够准确掌握换气的位置，这首歌就相对容易演唱。B段的难度稍高，需要特别注意配合鼓点的时机。副歌中「パッ」的部分，如果能像「パッ！」一样，将每个音清晰、短促地断开来唱，效果就会非常好！</p>
</details>

<details><summary>悪ノ召使</summary>
<p>原曲的最高音为G#5。如果采用降低一个八度的方式演唱，难度则为B级。考虑到歌词所表达的情感，比起明亮轻快的声音，使用更加厚实、沉重的音色会更容易表现角色的心境。另外，歌曲最后不仅发生了转调，还进入了无伴奏清唱的部分，因此建议提前确认容易唱不准的音高！</p>
</details>

<details><summary>マトリョシカ</summary>
<p>从B段过渡到副歌时，出人意料的转调带来了极强的冲击力！不过，这种独特的展开也直接增加了演唱难度。尤其是B段结尾到副歌开头的部分，还包含明显的音程跳跃，需要反复聆听并进行大量演唱练习，才能准确掌握。</p>
</details>

<details><summary>恋愛裁判</summary>
<p>虽然副歌的「涙の後に」会出现全曲最高音E5，但只要合理使用假声，就不需要勉强用真声完成，因此整体而言是一首比较容易演唱的歌曲。A段可以在「Oh！」和「そう」等位置进行短促的断句，并提前掌握鼓组军鼓的敲击时机。这样就能更轻松地跟上歌曲开头轻快的节奏！</p>
</details>

<details><summary>Tell Your World</summary>
<p>演唱时要展现出歌曲所描绘的广阔世界观，尽可能唱得富有动感和张力。保持积极、明朗的表情，并将视线投向远方。副歌中「Ahー」的长音需要稳定地延展到最后，因此平时必须认真练习腹式呼吸，尤其要训练将气息充分、平稳地呼出的能力！</p>
</details>

<details><summary>ヴィラン</summary>
<p>整首歌要注意感受富有弹跳感的节奏，尤其是副歌部分，如果有意识地使用更加厚实的音色，会更贴合歌曲的风格。副歌中的「花弁」和「下さい」要注意三连音的重音处理。如果能将「だっらっしー」「ぼっくっはー」唱出富有变化的断句和节奏感，效果会更好！</p>
</details>

<details><summary>ドーナツホール</summary>
<p>歌曲的BPM为126，速度稍快。尤其是A段，由于歌词比较密集，咬字和换气都是容易遇到困难的地方。不过，乐句通常以8拍或4拍为单位清晰地划分，因此推荐利用这些间隙进行换气。需要注意的是，每次吸气不宜过多，否则容易耽误下一句的进入时机。</p>
</details>

<details><summary>ロキ</summary>
<p>由于可以换气的位置相当有限，因此必须提前规划好每次换气后要一口气唱到哪里。如果能在「お互いになぁぁぁ」的部分使用帅气、有力量的嘶吼式唱法，就能留下十分强烈的印象！</p>
</details>

<details><summary>天ノ弱</summary>
<p>从开头的「今日はこっちの地方は」一直到歌曲结束，演唱几乎没有停歇的机会。由于整首歌缺少充分喘息的空间，而且最后一段副歌还会转调，因此建议提前规划好整首歌曲的气息与体力分配，确保能够完整唱到最后。另外，第一段B段从「メリーゴーランド」到「グルグルさ」附近，节奏会突然发生明显变化，需要特别注意。</p>
</details>

<details><summary>シャルル</summary>
<p>A段要重点注意咬字清晰度，B段则要着重处理低音。副歌尤其需要注意「謳って謳って」中从真声跳跃到假声、跨度达到一个八度的连续音程变化！此外，从假声重新切换回真声也是一大难点。如果反复演唱仍然无法顺利完成，可以先从唇颤音练习开始，尝试让旋律衔接得更加平滑自然。</p>
</details>

<details><summary>メルト</summary>
<p>演唱高音时，如果表情显得过于吃力，就可能影响「溶けてしまいそう」最后长音的延展，需要特别注意！副歌结尾的「好きなの」如果能像耳语一样轻柔地唱出来，就能形成更加鲜明的强弱对比。</p>
</details>

<details><summary>乙女解剖</summary>
<p>虽然整首歌曲并没有频繁出现特别困难的音程跳跃，但副歌最高音达到了C#6，因此必须具备稳定的高音演唱能力。A段和B段的演唱方式不断变化，有时需要使用略带停顿的断句，有时则需要跟随三连音的节奏。只要能够准确处理这些变化，同时稳定地唱出副歌高音，就能形成鲜明的强弱对比，让歌曲更有层次感！</p>
</details>

<details><summary>脳漿炸裂ガール</summary>
<p>整首歌曲对气息控制和咬字清晰度都有很高的要求，而且节奏模式会随着段落不断变化。对于第一段主歌，最好以能够一口气唱完「自問自答～マカロン食べたい」为最终目标！副歌部分可以尝试每拍用手指画一个圆，同时配合演唱，这样会更容易掌握重音的位置。</p>
</details>

<details><summary>ブリキノダンス</summary>
<p>歌曲的BPM高达172，速度相当快，加上歌词十分密集，因此是一首很难流畅演唱的歌曲。对于快速咬字的部分，建议先降低速度，准确掌握发音和节奏的时机，再逐渐加速练习。另外，如果嘴角下垂，声音就容易变得含糊，即使能够跟上语速，也可能缺乏足够的清晰度，因此推荐对着镜子检查自己的口型！</p>
</details>

<details><summary>六兆年と一夜物語</summary>
<p>这首歌的副歌非常忙碌，无论是快速咬字、旋律的上下跳动，还是换气安排，都具有相当大的挑战。如果难以准确掌握歌词进入的时机，推荐一边原地踏步一边演唱，或者配合左右交替迈步，通过全身的动作感受节拍，从而更自然地掌握演唱时机。</p>
</details>
